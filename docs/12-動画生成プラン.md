## 1. 目的

Markdown / リポジトリ文脈から **解説動画（MP4）** を Codex Studio 内で生成できるようにする。

### 方針（決定事項）

| 決定 | 内容 |
|------|------|
| NotebookLM 外注 | **しない**（本線にしない） |
| 第1映像プロバイダ | **Runway**（API 成熟・image/text→video） |
| 第2候補（後続） | Veo / Kling（同じ `VideoProvider` で差し替え） |
| 既定レンダー | **hybrid**（手順は slides+TTS、概念カットは Runway） |
| 入口 | Skill `/video-tutorial` + Tool `GenerateVideo` |
| 重処理 | Electron 非依存の `packages/media` |

### 非目標（当面）

- NotebookLM / HeyGen 等への丸投げ
- Sora 依存（シャットダウン予定のため候補外）
- Remotion 本格タイムライン（Phase 3）
- MCP 経由の公開（MCP 自体が Post-MVP）

## 2. パイプライン

```
入力: Markdown パス / プロンプト / オプション
        ↓
① Director（既存 LLM・監督プロンプト）
   → shotlist.json
     - id, kind: generative | slide | title
     - narration, durationSec
     - runwayPrompt / imageHint（generative 時）
     - slideMarkdown（slide 時）
        ↓
② Render
   - generative → Runway（非同期ジョブ → poll → mp4 クリップ）
   - slide → HTML テンプレ → PNG（+ TTS 音声）
   - title → 静止画 + TTS
        ↓
③ Compose（FFmpeg）
   → .codex/video/<slug>/out.mp4
```

### shotlist 例

```json
{
  "title": "RLS 入門",
  "voice": "alloy",
  "shots": [
    {
      "id": "01",
      "kind": "title",
      "narration": "この動画ではテナント分離の RLS を説明します。",
      "durationSec": 4
    },
    {
      "id": "02",
      "kind": "generative",
      "narration": "マルチテナントでは行レベルでデータを隔離します。",
      "runwayPrompt": "Abstract visualization of isolated data vaults, clean tech UI, slow camera push-in, 16:9",
      "durationSec": 5
    },
    {
      "id": "03",
      "kind": "slide",
      "narration": "マイグレーションで ENABLE ROW LEVEL SECURITY を実行します。",
      "slideMarkdown": "## RLS 有効化\n\n```sql\nALTER TABLE ... ENABLE ROW LEVEL SECURITY;\n```",
      "durationSec": 8
    }
  ]
}
```

## 3. アーキテクチャ

| レイヤー | パス（予定） | 役割 |
|----------|--------------|------|
| Skill | `.codex/skills/video-tutorial/SKILL.md` | 使い方・品質基準・いつ Tool を呼ぶか |
| Tool | `packages/tools/src/tools/generate-video.ts` | Agent から起動、進捗を返す |
| Media | `packages/media/` | Director / Runway / TTS / slides / FFmpeg |
| Shared | `packages/shared` | `video` 設定・権限カテゴリ `media` |
| Main | `packages/app/.../video-service.ts`（任意） | 進捗 IPC・設定 |
| CLI | `pnpm cli -- video generate …`（Phase 2） | CI / 無人再生成 |

```
UI Agent / CLI
    → GenerateVideo Tool
        → packages/media
            → Director (LLM adapters)
            → RunwayProvider
            → TtsProvider (OpenAI TTS 等)
            → SlideRenderer
            → FfmpegComposer
```

### VideoProvider 抽象（Runway 実装が第1）

```ts
interface VideoProvider {
  id: 'runway' | 'veo' | 'kling'
  generateClip(input: {
    prompt: string
    imageUrl?: string
    durationSec: number
    ratio?: string
    signal?: AbortSignal
  }): Promise<{ localPath: string; remoteUrl?: string; jobId: string }>
}
```

- Runway: 公式 REST（text/image → video）、ジョブ ID を poll、完了後にダウンロードして `.codex/video/.../clips/` へ保存
- 失敗時: そのショットを **slide フォールバック**（パイプライン全体は落とさない）

## 4. 設定スキーマ（案）

`AppSettings.video`（新規）:

```ts
video: {
  enabled: boolean
  /** hybrid | slides | generative */
  mode: 'hybrid' | 'slides' | 'generative'
  runwayApiKey?: string
  runwayModel: string          // 例: gen3a_turbo（実装時に公式 ID を確定）
  directorProvider?: LLMProviderId
  directorModel?: string
  ttsProvider: 'openai' | 'none'
  ttsVoice: string
  maxShots: number             // 既定 12
  maxGenerativeShots: number   // 既定 4（コスト抑制）
  outputDir: string            // 相対: .codex/video
}
```

- API キーは既存どおり Main で保持し、renderer へはマスク
- 日次予算（既存 `cost.dailyBudgetUsd`）と usage ログに **video ジョブ** も記録

権限: `ToolPermissionCategory` に **`media`** を追加。`GenerateVideo` は既定 `ask`。

## 5. フェーズ

### V1 — MVP（Runway + hybrid）

| # | 成果物 | 完了条件 |
|---|--------|----------|
| V1-1 | `packages/media` 骨格 + shotlist 型 | 単体テストで JSON 検証 |
| V1-2 | Director（LLM 1 回で shotlist） | 代表 MD からショット列が生成される |
| V1-3 | RunwayProvider | 1 クリップ生成・ダウンロード成功 |
| V1-4 | slides + OpenAI TTS + FFmpeg | PATH 上の ffmpeg で MP4 出力 |
| V1-5 | `GenerateVideo` Tool + Skill | Agent から `.codex/video/<slug>/out.mp4` |
| V1-6 | 設定・権限・マニュアル追記 | キー未設定時は slides のみで完走可 |

**受け入れ**: 短い Markdown（〜500語）から 30–90 秒の MP4 が生成される。Runway キー無しでも slides+TTS のみで完走。

### V2 — 実用

- CLI `video generate`
- 進捗 UI（ジョブ状態）
- 字幕 SRT
- ffmpeg 同梱（electron-builder extraResources）
- generative ショット数・解像度の設定 UI

### V3 — 品質

- Veo / Kling アダプタ追加
- Remotion または高度なカット編集
- 画面録画（Playwright）ショット種別

## 6. Runway 実装メモ

| 項目 | 方針 |
|------|------|
| 認証 | `RUNWAY_API_KEY` / 設定の `runwayApiKey` |
| 呼び出し | 非同期作成 → status poll（間隔 5–10s、上限数分） |
| 用途 | hybrid の `generative` ショットのみ（全編は作らない） |
| 比率 | 16:9 既定 |
| コスト | `maxGenerativeShots` で上限。超過分は slide に降格 |
| エラー | リトライ 1 回 → slide フォールバック → Tool 結果に警告 |

公式モデル ID・エンドポイントは実装時に Runway ドキュメントで再確認すること（本ドキュメントの例 ID は仮）。

## 7. リスクと緩和

| リスク | 緩和 |
|--------|------|
| Runway 課金 | generative ショット上限、日次予算、slides フォールバック |
| 生成に数分 | Tool 独自タイムアウト（Shell 30s とは分離）、進捗イベント |
| ffmpeg 未導入 | 検出して分かりやすいエラー。V2 で同梱 |
| コード映像の幻覚 | 手順ショットは必ず `slide`（Director プロンプトで強制） |
| キー漏洩 | 既存の settings redact と同じ経路 |

## 8. 成功指標

- Agent: `/video-tutorial path/to.md` で MP4 がワークスペース内に残る
- Runway 無しでも slides+TTS で完走
- 同一入力で再実行すると同じ `slug` 配下に成果物が揃う（再現性）
- NotebookLM への依存ゼロ
